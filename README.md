# Customer-Transaction-Prediction

# Dataset
There are a total of 200 features in this data set along with ID_code and target columns. The target columns contain 0 and 1 value where 0 means the customer will not do a transaction and 1 means the customer will do a transaction.

# Insights
• Logistic Regression achieved the highest accuracy among the three evaluated models in this banking dataset: Logistic Regression, Decision Tree, and Random Forest.

• Decision Tree demonstrated comparatively lower accuracy, indicating that it may not capture the underlying data patterns as effectively as Logistic Regression.

• Random Forest was also evaluated to improve predictive performance through an ensemble of multiple decision trees; however, its accuracy was lower than Logistic Regression.

• Based on the testing accuracy, Logistic Regression demonstrated better predictive performance on the given test dataset.

• Therefore, Logistic Regression was selected as the preferred classification model for this dataset, subject to further evaluation using precision, recall, F1-score.

• Logistic Regression Model will help the bank to identify which customer will make transactions in future.
